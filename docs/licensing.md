# Publication and data-safety review

## What was checked locally

The original starter README, tracked file list, challenge specification and agent instructions were inspected for licensing or redistribution terms. No LICENSE/COPYING/NOTICE file or explicit dataset redistribution grant was found in that local material. A publicly accessible repository or fictional dataset is not treated as a redistribution grant.

## What is excluded

This export does not include the competition dataset, problem statement, starter README/instructions, canonical answers, submitted output, annotation/routing lists, raw model or evidence traces, private conversation log, run directories, response/business caches, credentials, or the original Git metadata/history. Historical evaluation is reported only as aggregate measurements authorized for this portfolio description.

The demo CSV/JSON files and replay fixture were newly authored for this export. They use reserved `.test` addresses, fresh identifiers and new fictional records. The replay fixture is not a provider transcript or a renamed competition artifact.
